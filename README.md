# CodingLab - Landing Page

Projeto de prática de front-end que consiste em uma **landing page** institucional, desenvolvida utilizando apenas HTML e CSS puros.

## 📋 Sobre o projeto

Página inicial com seção de navegação (navbar) e seção hero (destaque principal), apresentando uma proposta de criação de sites usando exclusivamente HTML e CSS, sem frameworks ou bibliotecas JavaScript.

## 🖼️ Preview

A página exibe:

- **Logo/Marca:** CodingLab
- **Menu de navegação:** Home, About, Services, Contact, Feedback
- **Imagem de fundo (hero):** lentes de câmera fotográfica
- **Título principal:** "Create Amazing Website"
- **Subtítulo:** "Pure HTML & CSS Only"
- **Botões de ação (CTA):**
  - Learn More
  - Subscribe

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (background image, flexbox/grid para o menu, botões estilizados)

## 🚀 Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente no navegador, **ou**
3. Utilize uma extensão como o **Live Server** (VS Code) para rodar em ambiente local, por exemplo:
   ```
   http://127.0.0.1:5500/index.html
   ```
